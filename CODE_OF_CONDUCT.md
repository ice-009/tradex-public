# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the code and the ideas — not the people. Harassment, personal attacks and discriminatory language aren't tolerated.

Market talk is welcome, but this is a software project: don't use issues or discussions to promote paid tips, signals or trading services.

To report unacceptable behaviour, contact the maintainers through their GitHub profile. Reports are handled privately.
